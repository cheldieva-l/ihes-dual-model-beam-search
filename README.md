# IHES Dual-Model Beam Search

This repository contains a clean-room, replay-verified implementation of MLP-guided beam search for the 72-point puzzle in the [CayleyPy IHES Cube competition](https://www.kaggle.com/competitions/cayleypy-ihes-cube). It provides three English-language Kaggle notebooks:

1. a single-model global beam search;
2. symmetry and reverse (NISS-style) searches with exact path conversion;
3. a bidirectional symmetry/reverse search with complete reverse-frontier mapping, blind intersection, and an auditable known-path retention diagnostic.

The default controlled case is puzzle `106`, model `1778521793`, and beam width `1,000,000`. The known 24-move reference path is used only by the third notebook's optional diagnostic. Ordinary searches do not receive a known midpoint, midpoint hash, or protected path.

## Safety and reproducibility

- Every accepted path is replayed from the original, unrotated state with the official 18 generators.
- Submission validation replays all 1,003 rows, not only the replaced row.
- No generator is globally excluded. Immediate-inverse pruning exists as an explicit option and is disabled in the published configurations.
- Diagnostic last-slot protection is disabled by default. When enabled, it can retain a known state only after exact comparison proves that the state was generated by the current beam.
- The code reports where a known path is naturally retained, where it first drops out of true top-K, and where a diagnostic run protects it. This is an experiment-specific invariant, not a guarantee for all 1,003 puzzles.
- Model weights, competition data, private datasets, credentials, tokens, and generated frontier files are not committed. Kaggle assets are discovered at runtime.

## Model identity

Every run directory and log contains a canonical model identifier. The controlled run uses `1778521793`, resolving to `model_p888-t000_1778521793.json` and `p888-t000_1778521793_e32692.pth`. The registry also records the two Kaggle assets carrying model `1780290207` and the `ihes-e08192` Kaggle Model asset. Assets are referenced, not redistributed.

```bash
python -m pip install -e .
python -m pytest
python tools/validate_repository.py

```
